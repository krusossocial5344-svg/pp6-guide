# คู่มืออบรมครูประจำชั้น · ระบบ ปพ.6 โรงเรียนวัดบางปูน

คู่มือแบบสไลด์ เปิดบนเว็บ มีภาพหน้าจอจริงและหมุดตัวเลขชี้ว่าต้องกดตรงไหน
(ข้อมูลในภาพเป็นข้อมูลสมมติทั้งหมด)

- เลื่อนสไลด์: ปุ่ม ก่อนหน้า/ถัดไป · ลูกศร ← → · ปัดจอบนมือถือ
- กดตัวเลขตรงกลางแถบล่างเพื่อเปิดสารบัญ
- ลิงก์ไปสไลด์ที่ต้องการได้ เช่น `.../#13`
